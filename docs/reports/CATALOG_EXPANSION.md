# 전체 도감·이미지 보완 결과

작업일: 2026-10-21. Phase 2 도감·UI 범위를 보완함. 챗봇이 주 화면이며 Phase 3 전투·팀 기능은 시작하지 않음.

## 구현 결과

- 고정된 100종 기본값과 1,025종 상한을 제거함. 기본 실행은 원본 전체 pokemon 행을 수집함. 현재 **기본 1,025종 + 별도 폼 326개 = 1,351개 항목**임.
- 현재 PokéAPI pokemon 목록 1,351개와 ID 집합이 완전히 일치함. 누락 0개, CSV만의 추가 ID 0개임. [대조 증거](../evidence/catalog-coverage.json)
- 종 ID와 pokemon 리소스 ID를 분리함. 기본 포켓몬 ID·기존 대화는 유지하며, 별도 폼은 자기 타입·종족값·특성과 이미지 ID를 보유함. 같은 종의 설명은 공유하되 이를 다른 폼의 능력치 근거로 사용하지 않도록 안내함.
- 종 설명은 한국어·영어 CSV와 원래 게임 버전을 보존해 일괄 준비함. 항목 연결 문서 1,351개, 초기 색인은 메타 1,351개·문서 3,501청크임. 추가 질문의 관련 문서 수집에 따라 문서 청크 수는 변할 수 있음.
- 이름 목록과 자연어 조건 검색에 100개 단위 “더 보기”를 추가함. 조건 해석 캐시는 다음 페이지의 불필요한 모델 호출을 막고 도감·프롬프트·모델 설정 변경 시 새로 해석함. 실제 필드 조건 검증은 유지함.
- 목록에는 스프라이트, 선택 프로필에는 일러스트를 표시함. 일러스트 실패 시 스프라이트, 이후 대체 아이콘으로 전환함. 이미지가 없어도 선택·대화할 수 있음. 외부 요청은 PokéAPI sprites의 HTTPS 경로만 허용하며 지연 로딩을 적용함.
- 출처·이미지 권리 안내를 펼친 프로필과 데이터에 기록함. 이미지 파일을 Git에 포함하지 않음.

주요 파일: `backend/scripts/prepare_data.py`, 모델·카탈로그·목록/상태/검색 API, `frontend/src/components/PokemonImage.tsx`, 프로필·목록·페이지 처리, 실제 데이터·출처·테스트 및 README/API 문서.

## 범위와 한계

- 현재 원본의 전체 pokemon 리소스를 포함함. 독립 능력치가 없는 색·외형 차이만의 pokemon-form은 별도 채팅 항목으로 만들지 않음. 외형 전용 모든 변형까지 개별 선택하는 화면을 구현한 것은 아님.
- 일부 폼의 한국어 명칭이 원본에 없으면 영문 폼 식별자를 표시함. 임의 번역을 공식 명칭으로 만들지 않음.
- 이미지 주소 규칙에 해당 파일이 없을 수 있고 외부 네트워크도 실패할 수 있음. 대체 표시를 검증했으며 모든 1,351개 이미지의 존재를 보증하지 않음.
- 이미지 출처의 권리 안내는 [PokéAPI sprites LICENCE](https://github.com/PokeAPI/sprites/blob/master/LICENCE.txt)에 따름. 기본 도감·이미지 수록과 Champions 적격성·규칙 검증은 별개임.
- 조건 검색의 완전성은 모델이 구조화한 조건과 현재 원본 범위에 한정됨. 전투 승률·데미지·적격성을 추가로 구현하지 않음.
- 비밀 키·PDF·개인 학습 문서·로컬 대화/캡처 제외를 유지함. 비밀정보 점검을 거친 파일만 커밋·푸시 대상으로 삼음.
