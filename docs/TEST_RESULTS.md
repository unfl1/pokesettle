# Phase 1 구현 및 검증 결과

> 이 문서의 SQLite·Chroma 사용은 해당 단계 실행 당시 기록임. 현재 PostgreSQL + pgvector 저장·검색과 검증은 [PostgreSQL 전환 기록](POSTGRESQL_MIGRATION.md) 참조.

검증일: 2026-10-21 (Asia/Seoul). 범위: 필수 RAG 데이터·백엔드. **Phase 2 UI와 Phase 3·4 배틀/심화 기능은 시작하지 않았다.**

## 1. 구현 결과

- 실제 PokéAPI 기본 종 100건, 한국어 이름 100건, 종별 외부 설명 문서 100개를 확보함. 폼 중복으로 수량을 채우지 않음.
- JSON 검증, 항목별 검색 텍스트, Chroma `pokemon_meta`·`pokemon_docs`, 고정 ID upsert, 설정 기반 청킹·Top-k를 구현함.
- 외부 리소스 목록 검색, 세 구조화 프롬프트, 자체 문서 강제 포함, 질문별 후보 선별, 원문/검색 캐시를 구현함. 후보 조회 단계에서는 이름/URL 목록만 받고 선별 후 본문을 수집함.
- LangGraph는 `retrieve → generate` 두 노드임. 선택 메타 직접 포함, 외부 청크 병합·중복 제거, 실제 사용 근거만 반환, 근거 부족 유보를 구현함.
- FastAPI의 준비 상태·항목 목록/상세·세션·문서 준비·채팅·작업 조회 API, SQLite 저장, 소유 세션 검사와 안전한 오류를 구현함.
- GMS 공식 연결 주소와 `gpt-4.1-mini`로 실제 모델 실행을 확인함. 키는 `.env`에만 저장하고 파일 권한을 0600으로 제한함. 코드·문서·데이터에서 실제 키 문자열이 발견되지 않음.

변경 영역: `backend/`의 데이터·RAG·저장·API·스크립트·테스트, `data/`의 정규화 자료·출처·라이선스, `pyproject.toml`·`uv.lock`·환경 설정 예시·제외 규칙, README와 설계 문서의 구현 현황.

### 문제 해결

| 원인 | 수정 | 결과 |
|---|---|---|
| 초기 모델 응답의 원래 게임 버전명·인용 청크 혼동 | `source_versions` 분리, 인용 본문의 `Description (언어, 버전)` 식별자만 허용, `generic` 등 범위 표기와 게임 버전 구분 | 인용·버전 검증 실패 시 한 번 재생성 후 유보, 두 회귀 테스트로 검증 |

- 초기 실패 기록 보존, 최신 성공 실행 시각은 증거 JSON 참조
- 재생성 실패 시 수치 생성·유효하지 않은 인용 반환 방지


외부 API 검색은 웹 전체 검색이 아니라 **PokéAPI 정확한 리소스 이름 검색**임. 여러 외부 출처 유형 결합이나 MMR, RAG 전후 품질 비교를 구현한 것으로 표시하지 않음.

## 4. 비기능 및 제한

- NF2001: 실제 로컬 임베딩 검색 시간과 GMS 전체 처리 시간을 증거 JSON에 기록함. 단위 테스트의 시간은 사용자 응답 시간으로 간주하지 않음. TestClient는 background task 종료까지 기다리므로 case 시간은 접수 지연이 아닌 전체 처리 시간임. 동시 부하와 UI 체감 시간은 미검증임.
- NF2002: 실제 재수집 0회 및 재시작 후 캐시 유지, 질문 변경 시 저장 후보 재선별을 확인함. 강제 갱신 UI/API는 제공하지 않음.
- NF2003~4: `.env` 제외, 권한 0600, 소유 세션·입력 검증·안전한 오류를 검사함. UI에서의 노출 검증은 Phase 2에 남아 있음.
- NF2005: 데이터 준비·HTTP·색인·RAG·응용 서비스·저장·API를 분리함. Phase 1 저장 모델은 단순한 namespace JSON 캐시를 활용해 별도 테이블 수를 축소함.
- NF2006: 실제 직렬 호출·간격, 테스트로 재시도·Retry-After(초/HTTP 날짜)·금지 응답·실패 캐시 미등록을 확인함. 연락처 필수인 위키백과는 아직 수집하지 않음.
- NF2007: URL·시각·해시·원문 버전·권리 조건을 기록함. PokéAPI 프로젝트 라이선스와 이름/원문 등의 권리 제한을 보존함. 다른 사이트 권리를 확인한 것으로 확장하지 않음.
- 한국어 질문의 의미 검색 품질은 영어 중심 임베딩의 제약이 있음. 실제 질문 일부와 영문 검색어 결합을 확인했을 뿐, 폭넓은 한국어 검색 평가를 마친 것은 아님.
- 인용 ID 검사는 허구 ID를 막지만 주장과 문서의 의미적 일치까지 수학적으로 보장하지 않음. 이번 외부 설명 답변의 인용 청크는 수동 대조함.
- 데이터는 일반 도감 범위임. Champions 적격성·정밀 육성·상성/데미지 계산·KO/승률은 미지원이며, 규칙 레지스트리에도 미검증 명단을 등록하지 않음.
- 기본 설치에서 Streamlit은 제외함. PDF 지정 버전은 선택 의존성에 유지했으며 UI 단계에서 React 제출 수용 여부를 확인해야 함. 지정 버전을 대체 설치한 사례는 없음.
- 원문·모델 첫 다운로드를 제외한 로컬 실행을 검증함. 외부 서비스 가용성·장기간 캐시 운영·다중 프로세스·공개 배포 인증은 검증 범위 밖임.

## 5. 재현과 다음 단계

실행·재현 명령은 [README](../README.md)에 있음. 실제 모델 검증은 `verify_phase1 --live`로 별도 선택하며 공급자 크레딧을 사용함. 성공한 과거 답변은 대화 스냅샷으로 보존하지만, 모델의 다음 응답 문장은 달라질 수 있음.

Phase 2는 별도 요청 후 시작함. 다음 범위는 React 화면, 항목별 기록 조회, 자연어 탐색, 근거 운용 가이드, 진행/오류 화면 및 필수 전체 통합 검증임.
